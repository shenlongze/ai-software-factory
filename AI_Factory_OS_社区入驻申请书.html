01 行业痛点 PROBLEM

专业能力已经很多——Skill、MCP、Agent 百花齐放，但只有零件，没有机器。

  1. 生态割裂、没有链路：Cursor、TraeWork、Codex、Hermes 等各有专业 Skill 与 MCP，却彼此独立，串不成"从想法到交付"的一条完整链路。
  2. 没有统一管理：异构 Agent / Skill / MCP 无法统一调度、监控与治理，能力散落、责任不清。
  3. 编排门槛高：要让多个 Agent 协同，只能手写 / 硬编码 Workflow——配置复杂度高，业务一改就要重配，维护成本极高。
  4. Agent 执行黑盒：过程不可视、不可审计、不可治理，企业落地存在风险。
  5. 缺项目级管理与私有化能力：没有原生敏捷项目管理与分层测试；缺少标准接口，难以对接企业存量老旧业务系统。

02 解决方案 SOLUTION

设计灵感来自 PI Agent 极简基石、OpenClaw Skill 生态；采用 Create-Building 地基 + 可插拔插件架构。 定位：编排治理基座，不自研各类专业 Agent，复用市面成熟 Agent 能力。

核心能力

  1. Agent 遴选调度：可接入 Hermes、OpenClaw、Cursor、Codex 等第三方 Agent；根据任务自动择优调度，支持人工干预；不硬编码 Workflow，动态生成业务流程。
  2. 内置完整敏捷项目体系：想法 → 产品分析 & 商业评估 → 输出 PRD；拆解为 Sprint-Story-Task；Task 单测、Sprint 迭代测试、项目全量测试三层测试，附带项目边界监控。
  3. 运行时审计治理：对所有接入 Agent 统一监控、留痕、可追溯，解决 AI 黑盒问题。
  4. 部署与集成：兼容公有大模型，支持 Llama 本地私有化部署；全部能力输出标准化 API，支持企业二开对接老业务系统。

交付形态：CLI 底层服务 + 轻量化 WebUI。

AI Factory OS 是一款面向 OPC 单人创业者与中小企业的多 Agent 编排治理开源基座，基于 Apache-2.0 开源协议，累计 20 万行自研代码，整体进度 30%-40%，已可运行小型项目 Demo。

市面 Cursor、TraeWork、Codex 等工具仅聚焦代码辅助，功能单一、生态割裂、Agent 执行黑盒不可审计，缺少完整项目管理体系。

本项目借鉴 PI Agent 极简基座与 OpenClaw 技能生态思想，采用"地基 + 可插拔"架构，不重复研发专业 Agent，可接入 Cursor、Hermes、OpenClaw 等市面主流 AI 工具，通过智能遴选机制动态择优调度、自动生成业务流程，适配多变业务场景。

系统内置完整敏捷项目体系，支持从想法分析、商业评估、自动产出 PRD，到 Sprint、Story、Task 分层拆解，并配套三级分层测试与项目管控机制。底层实现 Agent 全流程运行监控、可观测、可审计治理，解决行业黑盒痛点。支持公有模型与 Llama 本地化私有化部署，全能力开放标准化 API，可对接企业存量业务系统。产品提供 CLI 底层能力与轻量化 WebUI，适配单人创业全流程作业与企业私有化智能化改造场景。
