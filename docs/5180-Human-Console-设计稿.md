# 5180 Human Console — 重构设计稿（K-7 Web 产品化）

> 日期: 2026-08-25 · 状态: Founder 确认（okokok）· 依据: 多轮讨论
> 目标: 把 5180 从"3 套独立页面(~28 页)"收敛成 Codex 风格的一套导航产品工作台。
> 范围: 本文档 = K-7（Web 产品化）改造范围；board（8011）= 开发者控制台，不在此文档。

---

## 1. 定位（一句话）

**5180 = 用户把一个想法做成软件产品的端到端工作台**（创建项目→发现→PRD→看板→执行→质量→交付）。
board（8011）= 开发者/运维/集成者的控制台（战役/员工/API/成本/审计/决策链）。

## 2. 布局（Codex 风格, 用户指定）

```
┌─────────┬──────────────────────────────────┬──────────────┐
│ 左栏 项目列表│ 顶栏: 项目名 · 生命周期状态 · 当前页      │ 右栏 上下文   │
│ ➕ 新建    ├──────────────────────────────────┤ (按需出现)    │
│ 🔍 搜索   │ 中央 项目工作区                     │ 审批卡片      │
│ ──────   │   [概览][发现][PRD][看板][执行][质量] │ 质量分       │
│ ● 进行中   │  ┌────────────────────────────┐  │ 执行日志      │
│ ● 墨笺    │  │ 发现对话 / 页面内容           │  │ 最近产物      │
│ ○ 已交付   │  └────────────────────────────┘  │              │
│          │  ┌────────────────────────────┐  │ (平时收起)    │
│          │  │ 底部: 全局对话输入(继续聊/改需求/│  │              │
│          │  │       /命令)                 │  │              │
│          │  └────────────────────────────┘  │              │
└─────────┴──────────────────────────────────┴──────────────┘
```

- 左栏 = 项目列表（Codex 任务列表的形态）：新建/搜索/分组(进行中·已交付)
- 顶栏 = 项目名 + 状态 + 当前页 + 设置 + 「🛠 开发者控制台」链接(→board)
- 中央 = 项目工作区（项目内 7 页）
- 底部 = 全局对话输入（发现澄清/改需求/命令，与 AI Factory 对话）
- 右栏 = 上下文面板，按当前上下文出现（审批/质量/日志/产物），不常驻

## 3. 信息架构（3 套 → 1 套）

**砍掉**:
- ModeToggle（普通 ↔ Expert 双模式）
- 普通模式"监控向"页: 决策 / 智能 / 工作流 / 产物（移 board 或并项目内）
- Header 项目选择器（选项目只在左栏）
- 右 FactoryPanel 常驻（改为按需）

**移去 board（开发者控制台）**:
- 决策链 / 智能 / 审计 / 成本监控 / 战役 / 员工 → board 已有或待补

**合并成一套项目工作区**（项目内侧栏 7 页）:
| 目标页 | 合并来源 |
|---|---|
| 概览 | ①Dashboard + ③overview + ③vision/roadmap → 生命周期进度 + 路线 |
| 发现 | ③discovery（对话，接底部输入） |
| PRD | ③prd |
| 看板 | ③backlog + ③sprint + ③todo → 任务看板（列表/泳道/状态） |
| 执行 | ③runtime + ③logs + ②runtime → 执行状态/日志/重放 |
| 质量 | ③quality（K-2 质量分 + K-3 复评） |
| 文档 | ①产物 + board 文档管理 → 项目文档树 |

**保留/收编**:
- 首页 = 左栏项目列表（进来第一眼，不再有独立 Dashboard 页）
- 设置 = ②settings + ①Providers（expert）→ 全局设置（模型/Provider/团队）

## 4. 数据与风格

- **数据**: 全部走真实 API（删 mock 兜底；后端不可达 → 明确"离线"标注，不混假数据）
- **风格**: 统一深色卡片风格（board 同款；5180 现在默认 light → 改默认 dark）
- **互链**: 5180 顶栏「🛠 开发者控制台」→ board；board 导航「🚀 产品工作台」→ 5180

## 5. 实现范围（K-7 拆分）

| 子战役 | 内容 | 验收 |
|---|---|---|
| **K-7a 布局收敛** | 删 ModeToggle/占位页/常驻右栏；左栏项目列表(新建/搜索/分组)；底部全局对话输入；顶栏状态 | 一套导航无残留；28 页 → 目标页集合 |
| **K-7b 页面并轨** | 项目工作区 7 页（概览/发现/PRD/看板/执行/质量/文档）全真实数据 | 每页真实 API 可断言；mock 归零 |
| **K-7c 互通+风格** | board↔5180 互链；深色风格统一；设置收编 | 互链可用；无两套皮 |
