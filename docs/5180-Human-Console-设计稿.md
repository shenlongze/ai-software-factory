# 5180 Human Console — 重构设计稿（K-7 Web 产品化）

> 日期: 2026-08-25 · 状态: Founder 确认（okokok）· 依据: 多轮讨论
> 目标: 把 5180 从"3 套独立页面(~28 页)"收敛成 Codex 风格的一套导航产品工作台。
> 范围: 本文档 = K-7（Web 产品化）改造范围；board（8011）= 开发者控制台，不在此文档。

---

## 1. 定位（一句话）

**5180 = 用户把一个想法做成软件产品的端到端工作台**（创建项目→发现→PRD→看板→执行→质量→交付）。
board（8011）= 开发者/运维/集成者的控制台（战役/员工/API/成本/审计/决策链）。

## 2. 布局（Codex 风格, 用户指定）

```
┌─────────┬──────────────────────────────────┬──────────────┐
│ 左栏 项目列表│ 顶栏: 项目名 · 生命周期状态 · 当前页      │ 右栏 上下文   │
│ ➕ 新建    ├──────────────────────────────────┤ (按需出现)    │
│ 🔍 搜索   │ 中央 项目工作区                     │ 审批卡片      │
│ ──────   │   [概览][发现][PRD][看板][执行][质量] │ 质量分       │
│ ● 进行中   │  ┌────────────────────────────┐  │ 执行日志      │
│ ● 墨笺    │  │ 发现对话 / 页面内容           │  │ 最近产物      │
│ ○ 已交付   │  └────────────────────────────┘  │              │
│          │  ┌────────────────────────────┐  │ (平时收起)    │
│          │  │ 底部: 全局对话输入(继续聊/改需求/│  │              │
│          │  │       /命令)                 │  │              │
│          │  └────────────────────────────┘  │              │
└─────────┴──────────────────────────────────┴──────────────┘
```

- 左栏 = 项目列表（Codex 任务列表的形态）：新建/搜索/分组(进行中·已交付)
- 顶栏 = 项目名 + 状态 + 当前页 + 设置 + 「🛠 开发者控制台」链接(→board)
- 中央 = 项目工作区（项目内 7 页）
- 底部 = 全局对话输入（发现澄清/改需求/命令，与 AI Factory 对话）
- 右栏 = 上下文面板，按当前上下文出现（审批/质量/日志/产物），不常驻

## 3. 信息架构（3 套 → 1 套）

**砍掉**:
- ModeToggle（普通 ↔ Expert 双模式）
- 普通模式"监控向"页: 决策 / 智能 / 工作流 / 产物（移 board 或并项目内）
- Header 项目选择器（选项目只在左栏）
- 右 FactoryPanel 常驻（改为按需）

**移去 board（开发者控制台）**:
- 决策链 / 智能 / 审计 / 成本监控 / 战役 / 员工 → board 已有或待补

**合并成一套项目工作区**（项目内侧栏 7 页）:
| 目标页 | 合并来源 |
|---|---|
| 概览 | ①Dashboard + ③overview + ③vision/roadmap → 生命周期进度 + 路线 |
| 发现 | ③discovery（对话，接底部输入） |
| PRD | ③prd |
| 看板 | ③backlog + ③sprint + ③todo → 任务看板（列表/泳道/状态） |
| 执行 | ③runtime + ③logs + ②runtime → 执行状态/日志/重放 |
| 质量 | ③quality（K-2 质量分 + K-3 复评） |
| 文档 | ①产物 + board 文档管理 → 项目文档树 |

**保留/收编**:
- 首页 = 左栏项目列表（进来第一眼，不再有独立 Dashboard 页）
- 设置 = ②settings + ①Providers（expert）→ 全局设置（模型/Provider/团队）

## 4. 数据与风格

- **数据**: 全部走真实 API（删 mock 兜底；后端不可达 → 明确"离线"标注，不混假数据）
- **风格**: 统一深色卡片风格（board 同款；5180 现在默认 light → 改默认 dark）
- **互链**: 5180 顶栏「🛠 开发者控制台」→ board；board 导航「🚀 产品工作台」→ 5180

## 7. OS v2（Founder 第二轮确认, 2026-08-26）

> 修正: 5180 不是"项目管理器", 是 **AI Factory OS**——公司/行业/部门/项目都是被管理对象。

### 7.1 OS 层级（默认一人公司根）
- 默认根 = **"我的公司"**（虚拟根目录, 当公司用）→ 项目直接挂下面
- 支持 **rename** / **复制出去**（copy 成独立公司）
- **部门**: 仅用户显式创建时才出现（默认无部门层）
- 左栏 = OS 层级树（公司/行业 → 部门(可选) → 项目）, 可折叠; 新建: 公司/行业/部门/项目

### 7.2 init 指定目录
- `factory init --dir <路径>` → 默认创建必要文件/文件夹（agents/skills/projects/providers/workspace + "我的公司"）

### 7.3 对话分域（入口要有说法）
- **项目外** = 全局对话（创建/讨论想法/发现）
- **项目内** = 只针对当前项目（改需求/发命令/状态）
- 同一个 Composer, 位置/上下文决定作用域; 真实接线（非占位）

### 7.4 项目首页（Founder 要求设计）
```
顶栏: ◆ AI Factory │ 📁 项目 │ 生命周期状态 │ 开发者控制台
左栏: OS 层级树                    中央: 项目首页
  🏢 我的公司                       ① 全生命周期条 (11 段 + 进度 + 当前卡点)
  ├─ 📁 项目A                       ② 任务 Todo (列表 ⇄ 看板泳道 可切换)
  └─ 📁 项目B                       ③ 运维/监控 (执行/质量分/成本/失败)
                                    ④ 项目内对话 (底部 Composer, 针对本项目)
```

### 7.5 敏捷项目管理（统一方法）
- 方法: **Agile (Scrum/Kanban)** — backlog/sprint/milestone 对齐现有后端
- Todo 双视图: **列表**（默认, 筛选/批量）⇄ **看板泳道**（待办/进行中/已完成, 拖拽）
- **编辑**: 行内编辑（标题/描述/优先级 P0-P2/负责人）
- **归档**: 完成任务 → 归档区（可展开查看）; 后端需补归档接口
- **审计/溯源**: 点任务 → 该任务审计链（创建/变更/执行/完成, 接 K-4 trace）
- 原则: **简单 · 直接 · 高效 · 易用**（不堆功能）

### 7.7 项目管理数据维度（Founder 确认 + 补充, 2026-08-26）

**已有维度**: 生命周期 11 段 · 任务(backlog/sprint/milestone + epic→story→task + 优先级/依赖/状态机) ·
质量分(K-2) · 成本(K-3) · 执行记录/重放(M5-1) · 决策记忆+审计链 trace(K-3/K-4) ·

**P0 核心（进 K-7b 项目首页）**:
| 维度 | 内容 |
|---|---|
| 健康度汇总 | 项目健康分(红/黄/绿) = 进度偏差+质量+阻塞+成本+失败 加权 |
| 计划 vs 实际 | 每节点计划工期 vs 实际, 关键路径延迟 |

| 里程碑进度 | 每个 milestone 完成/逾期 |
| **参与与贡献** | 本项目哪些 agent/skill 参与、做了什么、效果怎么样 |

工作量分布(agent/角色)

**P2 可选**: 交付物清单+覆盖率 · 变更统计(需求稳定性) · 团队效率趋势
