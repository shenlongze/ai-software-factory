# AI Software Factory — 软件市场价值评估 v1.0

> 评估日期: 2026-08-11 | 依据: 市场规模报告 + 竞品融资数据 + 代码实测
> 目的: 量化"这个软件值多少钱的市场, 以及 AI Factory 能切到多少"

---

## 0. 结论先行

**AI Factory 所处的赛道市场价值是真实的、巨大的, 而且还在高速增长。但"市场价值"不等于"你的价值"——从市场总量到 AI Factory 能拿到的份额, 中间隔着层层过滤。**

市场价值结论:
- 赛道总量: **百亿美元级且高增长** (AI 增强软件工程市场 2026 年约 $10B+, CAGR 20%+)
- 可切市场 (SOM): 取决于你聚焦哪一层, 当前最现实的是**中国信创私有化市场**
- 竞品标杆: Factory AI 以 15 亿美元估值融资, 证明资本认可此赛道价值
- **AI Factory 当前市场价值 = 技术底座的价值, 尚未被商业证明放大**

### 1.2 竞争资本体量 (赛道热度)

## 2. AI Factory 可切的市场 (分层)

### 2.1 按定位分层

| 层级 | 市场规模 | AI Factory 切入难度 | 现实性 |
|:---|:---|:---|:---|
| 全球平台层 (对标 Factory AI) | $10B+ | 极高 (资本+团队+客户差距) | 🔴 远期 |
| 单 Agent 写码工具 | $10B+ | 极高 (红海) | 🔴 不建议 |
| **中国信创私有化 (内网+本地LLM)** | **百亿级 (政企预算)** | **中 (你已具备能力)** | **🟢 最现实** |
| 垂直场景 SaaS | 细分 | 中 | 🟡 需聚焦 |

### 2.2 为什么"中国信创私有化"是 AI Factory 最现实的市场

- 政策驱动: 信创/自主可控是国策, 政企有强制私有化预算
- 竞品真空: Claude Code/Codex/Factory AI 全是云优先, **进不了内网** → 你几乎无直接竞品
- 能力匹配: 你的**内网运行 + 本地 LLM (Ollama) + 审计治理** 恰好是政企合规三件套
- 预算存在: 政企为"数据不出内网"愿意付企业级价格

**这是你区别于所有云优先竞品、且真实有预算的市场。**

## 3. 价值评估模型 (三层漏斗)

### 3.1 市场总量 (TAM): AI 软件生产平台, 百亿美元级

### 3.2 可服务市场 (SAM): 中国信创私有化 AI 软件开发, 百亿级 RMB

### 3.3 可获取市场 (SOM): 取决于 2 个月内能否做出真实案例

```
SOM = 首个垂直场景 (如"私有化 AI 生成 Flutter 应用") 
    × 首批客户 (政企/数据敏感行业试点)
    × 单客户价值 (私有化 License, 数十万到数百万/单)
```

**SOM 现在的瓶颈不是市场容量, 是"没有第一个案例"。**
一旦有真实案例, SOM 从"零"变成"一个可复制的垂直场景"。

---

## 4. 单客户价值 (定价视角)

| 客户类型 | 采购理由 | 合理定价区间 (私有化) |
|:---|:---|:---|
| 政企 (数据不出内网) | 合规 + 自主可控 | 数十万 - 数百万/单 |
| 中型软件公司 | AI 增强研发 + 审计 | 数万 - 数十万/年 |
| 小团队/独立开发者 | 低配免费/订阅 | 数十 - 数百/月 |

**关键: 私有化 + 审计 + 合规的客单价, 远高于纯 SaaS 工具。**
这正是"内网部署"比"云工具"商业上更值钱的原因——企业为合规付溢价。

## 5. 价值 vs 竞品对比

| 维度 | AI Factory | Claude Code / Codex | LangGraph / CrewAI | 信创低代码平台 |
|:---|:---|:---|:---|:---|
| 内网私有化 | ✅ 支持 | ❌ 云优先 | 🟡 自建 | ✅ |
| 本地 LLM (Ollama) | ✅ 支持 | ❌ | 🟡 | 🟡 |
| 审计/治理 | ✅ 强 | ❌ 弱 | ❌ 无 | 🟡 |
| 项目生命周期 | ✅ 全 | ❌ 单任务 | 🟡 | 🟡 |
| 软件生产 (非配置) | ✅ | 🟡 | 🟡 | ❌ 低代码 |

**AI Factory 的独特价值组合 = 内网 + 本地LLM + 审计 + 生命周期 + 软件生产**
这个组合在当前市场没有直接对标, 是真实的价值空位。

## 6. 估值视角 (投资人会怎么算)

### 6.1 当前状态估值依据

| 维度 | 现状 | 估值信号 |
|:---|:---|:---|
| 技术底座 | ⭐⭐⭐⭐ | 有独立价值, 但非直接变现 |
| 商业验证 | ⭐ (0 案例) | 最大折价项 |
| 市场空间 | 百亿级 | 支撑高天花板叙事 |
| 竞品对标 | Factory $1.5B | 赛道天花板锚点 |

### 6.2 估值跳跃逻辑

```
现在:  技术底座价值 (低, 无商业放大)
       + 内网/本地LLM 差异化 (有, 但未证明)
       + 0 真实案例 (最大折价)

2个月后 (若案例成功):
       + 真实交付案例 (商业验证 ⭐→⭐⭐⭐⭐)
       + 可核查审计数据 (治理壁垒落地)
       + 第一个可复制垂直场景
       → 估值锚点从"技术底座"跳升到"垂直平台"
```

**估值不是线性的, 是一次真实案例触发跳变。** 这正是 2 个月窗口的价值所在。

## 7. 风险与不确定性

| 风险 | 影响 |
|:---|:---|
| 本地 LLM (Ollama) 生成质量不足 | 影响"真实交付"成败, 需实测 |
| 政企销售周期长 | 2 个月难出政企单, 需先做小场景 |
| 竞品补内网能力 | 窗口期有限 |
| 模型能力依赖 | 底层模型决定上限 |

---

## 8. 最终价值判断

**AI Factory 的市场价值, 取决于 2 个月内能否完成一次真实交付。**
- 若成功: 从"技术底座"跳变到"私有化 AI 软件工厂"垂直平台, 价值量级 ×10
- 若失败: 仍是有技术底座的工具, 价值被压缩到"被集成/被收购"层

**一句话: 这个软件值一个百亿级市场的入场券, 但入场券的兑现, 押在 2 个月后的那一次真实交付上。内网+本地LLM 是它区别于所有竞品的入场通道, 审计治理是它加价的理由。**
