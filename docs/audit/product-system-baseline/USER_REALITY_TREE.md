# USER REALITY TREE — STEP 9 (2026-09-02)
> 用户视角 (非代码视角)

## User CAN (有生产证据)
```
- 创建/管理项目; 维护 backlog 任务; 查看 sprint/milestone/roadmap
- 在会话中提开发意图 → 看到 AI 制定开发计划 (持久化)
- 批准计划 → 任务自动创建 (带依赖顺序)
- 让任务按依赖自动执行 (等待/阻塞/失败传播真实可见)
- 中途停止任务 (CANCELLED)
- 任务失败后重试; 崩溃后系统恢复继续 (UNKNOWN 标注重排队)
- 看到计划自动完成/失败 (全任务 DONE → completed)
- 查看审计事件/任务历史/进度卡
- 触发外部 Agent 执行并拿到结果/补丁 (exec 域)
```

## User CAN PARTIALLY
```
- 提需求 (可存, 可查) — 但无法追踪需求到计划/任务
- 看到执行验证 (exec 域 test_result) — 不关联任务闭环
- 查看执行产物 — 仅 exec 域, 会话链任务无产物链接
- 调用专业角色 Agent (developer/pm...) — 有历史记录, 触发入口不明确
```

## User CANNOT (当前不可宣称)
```
- 完成"需求→PRD→工程→QA→发布"完整产品生命周期 (PRD 实体不存在)
- 按任务类型/成本选模型 (无动态模型路由)
- 需求变更 → 版本化 → 影响分析 → replan
- 从需求反查到最终产物 (追踪链断裂)
- 让系统从历史经验改进 (无学习闭环)
```

## User WILL EVENTUALLY BE ABLE TO (产品承诺 M3/M4)
```
- 需求变更受控回流 (PRD v2 + replan, M3)
- 经验→决策引用 (第二次任务用第一次经验, M4)
- 发布闭环 (M3/M4)
```
