# 17 — HERMES VS AI FACTORY LEARNING (P2-D CONTRACT, 2026-09-06)

- Hermes Agent-level Learning: Agent→Experience→Memory→Future Agent Context
  = 可插拔 agent-level mechanism (Hermes 自身 memory/skills)
- AI Factory Learning: Production Organization→Evidence→Experience→
  Observation→Candidate→Promotion→Capability→Router→Workforce→NextRun
  = organization-level production optimization
- **不混为一 domain**: Hermes memory 可作某个 Agent 的 learning provider,
  但不得作 AI Factory Learning SSOT (AI Factory Learning 全在 factory 域,
  锚定 canonical 生产事实)
