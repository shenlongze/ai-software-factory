## 1. 本阶段唯一目标

> 建立真正持久化的 Product Understanding SSOT, 让自然语言 Conversation 连续积累产品认知,
> 而不是每轮重新猜测。

## 2. 架构裁决 (审计后落点)

| 决策点 | 裁决 | 理由 |
|--------|------|------|
| 三套 Runtime 处置 | **本阶段不动** conversation_os / session/ / production_runtime | 用户禁令 (S49 §10): 删除/重写全部禁止 |
| Product Understanding 载体 | **新建 conversation-scoped domain**, 不复用 product_truth 六层 | product_truth = 正式资产层 (REQ/PRD/PLAN, approved gate); Product Understanding = 对话认知事实层 (confidence/source_message/supersession) — 不同层, 前者由后者 formalize |
| 存储 | `<root>/conversations/{cid}.json` 单文件原子写 (RLock + tmp + os.replace), 同 product_truth/chat_store 惯例 | 一 conversation 一文件 = Session Restart 完整恢复; 不造平行通用 store |
| Conversation id | `conv-` 前缀 | 与 conversation_os 的 conv_ 区分 (独立域, 目标 SSOT, legacy 不删) |
| 自然语言理解 | 解释器注入 (协议), 生产可接 LLM, 测试注入确定性翻译 | "Internal Structured, External Natural"; 无 keyword 强制 |
| Adaptive Clarification | Sufficiency gaps 启发式 + 可扩展 question 策略 | 替代固定 problem→user→core_features 问卷 |
| Intent | 不参与 Product 状态机 (仅 router, 已有) | S49 §1 |
| PRD | conversations 域内 versioned PRD 对象 (source_product_understanding_version) | S49 §8; 不破坏现有 PRD.md artifact |

## 3. Domain Model (冻结)

```
Conversation (conv-*)
 ├── messages: [{id, role, content, created_at}]
 └── understanding (version 单调递增)
      └── facts: [Fact]
           Fact: {id, conversation_id, type, content, status,
                  source_message_id, confidence, provenance,
                  supersedes: [id], created_at, updated_at}
           type ∈ IDEA | REQUIREMENT | CONSTRAINT | DECISION | QUESTION | FUTURE_IDEA
           status ∈ PROPOSED | CONFIRMED | SUPERSEDED | REJECTED
```

- **Supersession (Test D)**: 同 identity_key (type+规范化 content) 已存在且非终态 → 新 fact 顶替
  (旧 status=SUPERSEDED + superseded_by), 不产生两个冲突事实。
- **有效事实** = status ∈ {PROPOSED, CONFIRMED} (CONFIRMED 优先于 PROPOSED 同 key)。

## 6. 边界 (S49 §10 严禁)

不删除 conversation_os/session、不重命名目录、不重写任何 runtime、不迁移历史数据、不统一全部 API。
本阶段新增域为**目标架构本体** (第四阶段 §29 裁决 conversation_os → RETIRE 的替代), legacy 暂留。

## 7. 设计决策记录 (ADR 级)

1. **存储**: `<root>/conversations/{cid}.json` 单文件 (conversation+messages+facts+version 原子一致)。
   与 product_truth (`<root>/product_truth/`) 隔离 — 认知层 vs 正式资产层。
2. **Supersession**: identity_key (type+norm) 精确同 → 原地刷新; 同 dimension 槽不同值
   (平台 手机→网页) → SUPERSEDED 历史 + 新 fact 顶替。Test D 满足。
3. **解释器**: 注入协议, 默认确定性中文规则 (无 LLM 依赖, 测试可复现); 生产可接 LLM。
4. **PRD**: create 需已有 Understanding (空会话拒绝派生 — 诚实); draft 可 update 派生新版本;
   approved 不可原地改。provenance = source_product_understanding_version 单调。
5. **API**: 新 Conversation Domain 端点挂在 /api/conversations/{id}/product-understanding*,
   与 legacy conversation_os (conv_*) 路径共存 — legacy 未动 (S49 §13)。
