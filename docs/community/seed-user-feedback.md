# Seed User Feedback — AI Factory

> 位置: docs/community/seed-user-feedback.md | Sprint: S10-045 | 种子用户反馈收集模板
> 用途: 邀请 5-10 名开发者实测后收集反馈, 驱动 v0.2

---

## 用户反馈模板

### 基本信息

```
你的角色: (独立开发者 / 创业团队 / AI 工程师 / 其他)
工作规模: (个人 / 1-10人 / 10-50人 / 50+人)
主要语言: (Python / JS / Java / Go / 其他)
LLM 工具经验: (Claude Code / Cursor / Copilot / 其他 / 无)
```

### 使用场景

```
你尝试了哪个场景? (修改代码 / 生成测试 / 代码分析 / 项目维护 / 自动化 / 其他)
你在什么项目上试的? (个人项目 / 公司项目 / 学习项目)
```

### 第一次成功时间

```
从开始安装到第一次成功执行 AI 任务, 花了多久?
  (1-5 分钟 / 5-15 分钟 / 15-30 分钟 / 30+ 分钟 / 没成功)
卡在哪一步? (安装 / 配置 key / init / demo run / run / 其他)
```

### 遇到的问题

```
遇到过什么错误或困惑?
  (失败提示看不懂 / 概念不懂(provider/agent/task) / 文档找不到 / 其他)
你是怎么解决的? (看文档 / 试错 / 放弃了 / 其他)
```

### 希望增加功能

```
你最希望 AI Factory 加什么?
  (UI 界面 / 项目 RAG / 更多 Agent / 插件市场 / 定时任务 / 其他)
有没有你预期存在但没找到的功能?
```

### 是否愿意继续使用

```
你会把它纳入日常工作流吗? (会 / 可能 / 不会)
为什么?
愿意为此付费吗? (每月 ¥0 / ¥50-100 / ¥100-300 / ¥300+)
会推荐给朋友/同事吗? (会 / 可能 / 不会)
```

### 开放式反馈

```
最喜欢的一点:
最讨厌的一点:
一句话评价 AI Factory:
对比你用过的其他 AI 工具, 它独特的价值是?
```

## 采集方式

1. **GitHub Issues**(推荐): 模板复制到 issue, 标题 [feedback]
2. 或 Google Form / 腾讯问卷
3. 每个种子用户 15-20 分钟(含实测 5 分钟体验)

## 反馈 → 行动映射

| 反馈 | 行动 |
|---|---|
| 卡在安装 | 修 setup.sh / 推 PyPI |
| 失败看不懂 | 统一错误格式(已做 S10-044) |
| 概念难懂 | CLI 引导 / 文档增强 |
| 想要 UI | v0.2 UI Console 优先级提升 |
| 想要 RAG | v0.3 Project RAG |
| 愿意付费 | Enterprise 方向验证 |

## 种子用户招募建议

- 目标: 5-10 名
- 渠道: 开发者社区 / 朋友圈 / GitHub / 技术群
- 激励: 早期访问 + 反馈采纳记录 / 未来 Enterprise 折扣
