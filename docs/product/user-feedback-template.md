# User Feedback Template — AI Factory

> 位置: docs/product/user-feedback-template.md | Sprint: S10-043 | 第一批用户反馈体系

---

## 用途

种子用户(5-10 名)实测后收集结构化反馈, 驱动 v0.2 优先级。

## 用户类型

- [ ] Developer(独立开发者/工程师)
- [ ] Startup(创业团队技术负责人)
- [ ] AI Engineer(平台/AI 团队)

## 基本信息

```
角色/职位:
公司规模: (个人 / 1-10 / 10-50 / 50+)
使用场景: (个人项目 / 团队协作 / 企业平台)
LLM 经验: (入门 / 熟练 / 专家)
```

## 核心问题

### 1. 为什么使用?

- 你最初为什么尝试 AI Factory?
- 你希望它解决什么问题?

### 2. 哪里困难?

- 安装/初始化有没有卡住?
- 哪个概念最难理解?(provider / agent / task / objective / env key)
- 有没有命令报错不知道怎么办?
- 有没有文档看不懂的地方?

### 3. 缺什么?

- 最希望下一个版本加什么功能?
- 有没有你预期应该有但没找到的功能?

### 4. 愿意长期使用吗?

- 你会把它纳入日常工作流吗?
- 愿意每月为此付费吗? 大概多少?
- 会推荐给同事/朋友吗?

## 采集方式建议

1. 邮件/表单(Google Form / 腾讯问卷)

3. 5-10 名种子用户, 每人 15-20 分钟(含实测)
