# 产品愿景 — AI 员工操作系统

> **中文版** · [English](./vision-en.md)

## 一句话理念

**AI Factory 是 AI 员工操作系统 —— 管理你的 AI 员工, 而不是用 AI 聊天。**

## 从"人直接写代码"到"人管理 AI 组织"

### 传统软件开发

```
人类
  ↓
代码
```

### AI 时代

```
人类
  ↓
AI 组织              ← AI Factory(操作系统)
  ↓
AI 员工              ← 有角色/技能/权限的 Agent
  ↓
软件产出              ← 代码/测试/文档/产物 — 全部可审计
```

传统工具让人与代码进行"一问一答"式的对话。
AI Factory 让人**站在 AI 员工组织之上**——规划、评审、审批、审计。

## 定位

> **Devin 替你干活, AI Factory 管理你的 AI 员工。**

- Devin / Cursor / Claude Code 是优秀的"员工"。
- AI Factory 是组织、治理、审计这些员工的"操作系统"。

## AI Factory 提供什么

| 层 | 能力 |
|---|---|
| **组织** | Agent 即员工: 角色/技能/团队(组织隐喻) |
| **决策** | AI Router: 什么任务用哪个模型(User > Agent > Project > System > Fallback) |
| **执行** | 真实 LLM 执行: Task → Agent → LLM → 沙箱 → 产物 |
| **治理** | 审批门/权限链/人在环上 |
| **审计** | 全事件溯源: 谁/什么/何时/哪个模型/花了多少钱 |

## 目标用户

1. **开发者** — 多模型可控、真实执行、成本可见
2. **创业团队** — 一个人 + AI 员工交付产品
3. **企业 AI 团队** — 规模化的治理、合规、审计

## 我们的信念

- **人在环上, 决策权在人。** AI 提议, 人类批准。
- **一切以证据为准。** 每个声明都有产物和事件支撑。
- **治理是护城河。** 管理 AI 才是问题, 生成文本不是。
- **开源核心。** 社区在壳上构建, 企业为治理付费。
