# AI 经验学习平台（AI Experience & Learning Platform）— 可立项产品规格

> 版本: 0.1 (可立项) | 日期: 2026-08-24 | 状态: 记忆雏形已实现, 学习闭环设计（P2）
> 来源: AI Factory 方案书 §7 学习与自我进化 · §17 自我进化体系专项 · §2.9.1（P2）

---

## 1. 产品概述

**一句话**: 让 AI 越用越好且可控——经验沉淀、画像学习、评价回写、自我进化（学习/监控/完善/发现/修复），全部带护栏。

**给谁**: AI 平台团队 / 长期使用 AI 的组织

**解决什么**:
- AI 不学习（同样的坑反复踩，每次从零开始）
- 学习不可控（AI 学到错的东西/成本失控）
- 进化不可证明（"越用越好"无法量化）

**价值主张**: "AI 的学习 = 可沉淀 + 可控制 + 可证明，不是黑盒训练"。

## 2. 背景与机会

- **痛点**: 企业 AI 用久了"原地踏步"——经验不沉淀、决策不引用、评价不回写
- **机会**: 学习是 AI 价值的复利（用越久越值钱）；"可控学习"是企业敢让 AI 长期用的前提
- **竞品对照**: LangChain Memory（会话记忆, 无组织级学习）· 通用 RAG（检索, 无闭环进化）· 本产品差异 = **组织记忆 + 决策引用 + 评价回写 + 五维自我进化闭环**
- **战略地位**: P2——价值复利层（先有内核/记忆，再进化）

## 3. 目标用户与场景

| 用户 | 场景 | 价值 |
|---|---|---|
| AI 平台团队 | "AI 第二次遇到同类问题会引用第一次经验吗" | 决策引用闭环 |
| 研发管理 | "AI 修复成功率在提升吗" | 评价回写 + 指标 |
| 长期用户 | "AI 会自己发现并修复问题吗" | 五维自我进化 |

## 4. 功能范围

### MVP（已实现 ✅）
- [x] **经验库**（ExperienceStore: add/records/过滤）
- [x] **经验检索**（retrieval.search: 关键词 + 项目过滤 + confidence 排序）
- [x] **memory API**（5 函数: search/learn/stats/agent/export）
- [x] **五维标签设计**（§7.2.1: 域×技术栈×任务类型×项目×通用度）

### P1（待做）
- [ ] **学习闭环**（M4-1）: 经验→画像→决策引用→评价回写（第二次同类任务引用第一次经验）
- [ ] **学习护栏**（M4-2/§7.3）: 开关/样本可信度/预算上限/回滚
- [ ] **决策记忆回流**（M4-3/E5）: 审批决策落记忆，下次少审

### P2（远期）
- [ ] **五维自我进化**（§17）: 学习/监控/完善/发现/修复闭环
- [ ] **自我修复**（§17.13）: 检测→诊断→策略→应用→验证→学习
- [ ] 学习 vs 训练边界（§17.15: 何时才需要训练）

### 明确不做
- 不做模型训练（学习≠训练, §17.15——当前三层学习都不动模型）
- 不做无护栏的自动进化（可控性铁律）

## 5. 端到端用户流程

```
1. 任务完成 → 经验自动沉淀（提取: 问题/方案/结果 → 五维标签）
2. 第二次同类任务 → 检索引用第一次经验（决策引用）
3. 执行后 → 评价回写（这次用了经验, 结果如何 → 置信度更新）
4. 审批决策 → 回流记忆（E5: 下次类似审批少审/快审）
5. 护栏: 低样本不主导 · 超预算阻断 · 可回滚
6. 进化（P2）: 监控 → 发现问题 → 自我修复 → 验证 → 学习（五维闭环）
```


## 7. 验收标准（可立项门槛）

```
1. 第二次同类任务 → 引用第一次经验（决策引用断言）
2. 低置信经验不主导（护栏断言）
3. 审批决策 → 记忆回流（下次少审断言）
4. 学习可回滚（改坏的经验可撤回）
5. 全量回归 0 新增 + git clean
```

## 10. 风险与依赖

| 风险 | 缓解 |
|---|---|
| 学习不可控（学到错东西） | 护栏（样本可信度/预算/回滚 §7.3）+ 低置信不主导 |
| 学习与训练混淆 | §17.15 明确: 当前学习不动模型, 训练是远期 |
| 决策引用误导 | 来源标注 + 置信度门槛（§7.2.1） |
| 依赖 | 经验库/检索（✅）· 学习闭环（📐 M4） |
