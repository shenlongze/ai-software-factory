## 1. 项目介绍

**AI Software Factory = AI 员工操作系统 (AI Workforce Operating System)。**

治理驱动的 AI 软件生产平台: 管理你的 AI 员工, 而不是用 AI 聊天。
AI 从"一问一答的聊天机器人"变成**有岗位、有职责、有流程、有审批、有审计、
有成本账单的员工**。

```
Human → AI Organization → AI Workers → Software Output (全部可审计)
```

| 能力 | 说明 |

## 3. 安装方式

### 源码安装(当前推荐)

```bash
git clone https://github.com/shenlongze/ai-software-factory.git
cd ai-software-factory
bash scripts/setup.sh        # Python 3.12+ venv + 依赖 + 冒烟 (幂等)
```

### wheel 安装(已验证, PyPI 发布待定)

```bash
pip install ai-software-factory   # 即将支持
# 当前: 本地构建 wheel 后 pip install dist/*.whl
```

## 4. 快速体验

```bash
# 1. 配置 LLM (环境变量, 不落盘)
export DEEPSEEK_API_KEY="sk-..."

# 2. 初始化
factory init --non-interactive --provider deepseek
factory doctor                  # 全部 PASS 即可开始

# 3. 创建项目 + 运行任务 (真实执行)
factory project create --repo-path ~/my-app
factory run --project ~/my-app --task T-001 --agent backend-1
factory run-status --id <结果ID>

# 4. 查看审计
factory audit
```

完整 5 分钟体验: [docs/getting-started/quick-start-zh.md](../getting-started/quick-start-zh.md)

## 7. Known Limitations

- 单机部署(无多租户/云托管)
- API 无认证(本地 localhost 模式; 远程部署需自行加反向代理认证)
- exec CLI 的 `run-status` 查询为顶层命令(非 run 子命令)
- 前端 Web 管理台为观察/审批用, 执行入口以 CLI 为主
- Router 为确定性规则链(智能增强在 Future)
- 仓库公开后 CI 自动验证生效(当前本地验证)
