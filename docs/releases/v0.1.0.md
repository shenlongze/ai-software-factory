# AI Factory v0.1.0

> AI Workforce Operating System — 管理你的 AI 员工, 而不是用 AI 聊天。
> License: Apache-2.0 | Requires: Python >= 3.12

## Features

### AI Workforce OS Foundation
- AI 员工操作系统: Human → AI Organization → AI Workers → Software Output
- CLI-first 完整入口(17+ 命令), 无 UI 也完整可用
- 隔离 Demo Workspace(`factory demo`)

### Control Plane
- Provider 生命周期管理(providers.json): deepseek / openai / anthropic / ollama
- API Key 引用机制(env: 引用, 不落盘、不写明文)
- `factory init` 首次引导 + `factory config` 运行时配置

### Multi-model Support
- Model Catalog: Provider→Model 两级结构, capabilities/context/cost
- 本地模型支持(ollama, 无需 key)

### LLM Router
- 五层决策链: User > Agent/Skill > Project > System > Fallback
- 可解释输出 ModelChoice(source/reason/score)
- Router 决策全程审计(router.decided 事件)

### Agent Runtime
- 真实 LLM 执行: Task → Agent → LLM → 沙箱 → Artifact
- 审批门: AI 产出等待人工批准
- 执行报告: tokens / cost / latency / status

### CLI Management
- `factory init` / `doctor` / `config` / `start` / `service` / `demo`
- `factory project create/list` / `run` / `run-status`
- `factory agent/skill/task/router/rag/audit`(管理骨架)

### Audit Foundation
- append-only 事件库: 谁/什么/何时/哪个模型/多少钱
- `factory audit` 事件查询
- 全链路审计(execution/org/provider/router 事件)

## Quick Start

```bash
git clone https://github.com/shenlongze/ai-software-factory.git
cd ai-software-factory
bash scripts/setup.sh

export DEEPSEEK_API_KEY="sk-..."
factory init --non-interactive --provider deepseek
factory doctor

factory project create --repo-path ~/my-app
factory run --project ~/my-app --task T-001 --agent backend-1
factory run-status --id <result-id>
factory audit
```
