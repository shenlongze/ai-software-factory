## Blockers (按严重度)

```
P0-1  用户第一步无法开始: 无对话输入 UI + 无 POST /api/projects (405) + 无 chat 端点 (404)
      — "一句话创建 App" API 与 UI 双层缺失 (设计有 POST /api/projects {idea}, 实现未落地)
P0-2  无 Workflow 启动端点: 建出项目也无法从 Web 启动执行链 (CLI 有 org workflow run, Web 无)
P1-3  Conversation Layer 整体缺失: 无对话持久化/上下文; 底部输入框占位 (提交无请求)
P1-4  Workspace 项目树硬编码 mock: 新用户看到假 "记账 App", 与真实空数据空间不一致
P2-5  Dashboard CLI 命令不精确: "factory idea new" 实际应为 factory product idea create
```
