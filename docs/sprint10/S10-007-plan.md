## 四、S10-007 实施计划 (五阶段, 每阶段 commit + 验证)

```
阶段一: 配置独立化 (解除 Hermes 耦合)
  - factory.config 支持: LLM_PROVIDER/LLM_API_KEY/LLM_MODEL/LLM_BASE_URL/DATA_DIR/PORT
  - 优先级: 项目 .env > ~/.factory/config.json > 进程环境 (开发兼容)
  - workflow_runner 改为读配置 (不再硬读 ~/.hermes/.env)
  - 测试: 无 ~/.hermes/.env 环境可跑 (用配置 key)

阶段二: factory CLI MVP (一键启动)
  - bin/factory start|stop|status (纯 shell 或 python 入口)
  - start: 环境检查 (python/node) → 依赖检查 → 配置检查 (key 缺失提示) →
           启动后端 (uvicorn 8011) → 启动前端 (vite 5180) → 打开浏览器
  - stop: 杀前后端 (pid 文件) | status: 端口/进程/数据目录
  - 不要求用户懂 uvicorn/vite/PYTHONPATH/npm

阶段三: 首次启动体验
  - Workspace 首次进入 (无项目) → 优先显示"你想创建什么软件?" 创建表单 (已有雏形, 强化)
  - 创建成功 → 自动提示/显示"开始开发"按钮 (run-status none → 显示; 已接 API)
  - key 缺失 → 引导文案 (告诉我配置方法)

阶段四: 真实用户验收 (模拟普通用户)
  - 起服务 → 打开 → 创建"一个简单记账 App" → 开始开发
  - 验证 7 点: Product Agent 工作/需求分析/Timeline/Artifact/Review/继续执行/最终产物
  - 记录: 成功点/失败点/缺失功能 (诚实)

阶段五: 文档
  - README.md: 3 分钟运行 AI Factory (安装/配置/启动/第一次使用) — 产品文档非开发者文档
```
