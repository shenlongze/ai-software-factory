## 一、Current Architecture Audit (实测代码)

### 1.1 org 层 (factory-org/org/projects.py)

```
ProjectState: IDEA / ACTIVE / MAINTAINED / ARCHIVED (4 态, 无 DRAFT/DISCOVERY/CONFIRMED/...)
PROJECT_TRANSITIONS: idea→(active,archived) / active→(maintained,archived) ...
Project(_OrgModel): id/name/user_id/goal/lifecycle/repo_path/language/framework/
  build_command/test_command/project_type/analysis_ref/baseline_ref/snapshot_ref/
  created_at/updated_at (无 slug/draft/discovery/bindings 字段)
存储: org/projects.json (集中式 _SectionStore, ProjectSection 继承)
  ProjectStore: save/get/list/delete (org 门面)
  ProjectLifecycle: create_project (lifecycle 默认 idea) / get / list / delete /
    transition_to (PROJECT_TRANSITIONS 校验) / archive
```

### 1.2 Console 层 (factory-console)

```
service.create_project(idea, name?, project_type?, tech?)
  → org ProjectLifecycle.create_project(name, goal=idea) → lifecycle=idea
api/projects.py: create_project (extract_project_name slug 兜底) / suggest_project
  (AI 提议名称/理解/问题 — 一次性响应, 未持久化为 Session)
fastapi_adapter: POST /api/projects / POST /api/projects/suggest / PATCH/DELETE
  /{id} / POST /{id}/start /chat / GET run-status/timeline/artifacts
运行目录: workflow_runs/{project_id}/{run_id}/{app,dist,progress,report}
  (代码临时沙箱, 无项目生命周期目录)
```

### 1.3 与目标模型差距

| # | 差距 | 影响 |
|---|------|------|
| 1 | 状态机缺 DRAFT/DISCOVERY/CONFIRMED/DEVELOPMENT/RELEASE/MAINTAIN | 无法表达草稿/澄清/确认/生产/发布 |
| 2 | 无 slug/draft/discovery/bindings 字段 | 无目录名/草稿标记/沟通记录/绑定 |
| 3 | 无项目目录 (org/projects.json 集中式) | 无 idea/discovery/management/runtime 空间 |
| 4 | 创建即正式命名 (name 必填 → slug) | 无 unnamed-project draft |
| 5 | suggest 一次性 (不持久化 Session) | 沟通不可追溯 |
| 6 | 无 confirm/rename 端点 | 无法事务性改名 |
| 7 | 无 workspace 目录索引 | 目录信源缺失 |

### 1.4 兼容约束 (不破坏)

```
- 旧项目 (ledger-app/markpad 等 lifecycle=idea/active) 在 org/projects.json
- 既有 API 契约 (POST /api/projects {idea,name?} → 正式项目) 被前端/测试依赖
- suggest 已被前端两阶段卡片使用 (S10-007 收尾)
- S10-006.5 项目管理 (PATCH/DELETE) / P1-A (start/chat) 依赖 org Project
```

## 二、Implementation Plan (S10-009, 每 Task 独立 commit + 测试)

```
Task 1 (S10-009-001): Project Entity 扩展
  org/projects.py: ProjectState += DRAFT/DISCOVERY/PRODUCT_DEFINED/DESIGN/
    ARCHITECTURE/CONFIRMED/DEVELOPMENT/RELEASE/MAINTAIN (宽容解析, 旧值保留)
  Project += slug:str / draft:bool=False / discovery_ref / bindings 字段 (带默认)
  PROJECT_TRANSITIONS 扩展 (draft→discovery→...→maintain→archived)
  测试: 状态解析兼容 / 转换表合法性 (旧值不破坏)

Task 2 (S10-009-002): Lifecycle State Machine 迁移方法
  ProjectLifecycle: transition_to 支持新状态 (受控); 旧值 idea/active 正常流转
  测试: 新旧状态流转 / archived 终态 / 非法流转拒绝

Task 3 (S10-009-003): Directory Structure + Workspace Index
  新 ProjectSpaceStore: workspace/projects/{slug}/ 布局 (project.json 信源 +
    idea/discovery/product/design/architecture/workflow-instance/source/artifacts/
    knowledge/runtime/logs/management 目录骨架)
  WorkspaceIndex: org/projects.json 降为查询缓存 (目录信源)
  lazy migration: 旧项目首次访问回填目录镜像
  测试: 目录创建 / 索引镜像 / 懒迁移幂等

Task 4 (S10-009-004): Draft + Discovery Persistence
  POST /api/projects {idea} → 创建 DRAFT (unnamed-project-{ts}, lifecycle=discovery,
    draft=true) + idea/conversation.json + idea.md + discovery/conversation.json
  POST /api/projects/{id}/discovery/answer {question, answer} → 持久化
  POST /api/projects/{id}/discovery/complete → product_defined (product-definition.md)
  suggest 保留 (作为 discovery session 起点)
  测试: draft 创建 / 目录生成 / 问答持久化 / complete 产物

Task 5 (S10-009-005): Confirm + Rename 事务
  POST /api/projects/{id}/confirm {name} → 事务: slug 校验唯一 → 快照 →
    project.json 更新 → 目录 rename (os.replace 原子) → 索引/引用更新 →
    lifecycle=confirmed → 回滚保障
  API: get project / list workspace projects (draft 标记) / update lifecycle
  测试: rename 事务 / 文件不丢失 (conversation/discovery 保留) / 引用更新 /
    冲突 slug 拒绝 / 回滚

Task 6 (S10-009-006): 兼容 + 验收场景
  场景1: "我要做一个AI笔记软件" → unnamed (DISCOVERY, draft) + idea/discovery 目录
  场景2: 确认 "AI Note" → ai-note/ + 引用更新
  场景3: 既有项目 (ScorePocket/MarkPad) 正常 (懒迁移)
  全量 pytest + 回归 (console 449 → 全绿)
```
