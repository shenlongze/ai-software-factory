# S10-029 Task 1 — AI Factory 用户画像

> 日期:2026-08-14 | Sprint: S10-029 Product Validation | 产品分析,未修改代码
> 目标:定义四类核心用户画像,为产品定位/场景/商业模式提供基础

---

## 1. 开发者画像

| 维度 | 描述 |
|---|---|
| 代表 | 独立开发者 / 全栈工程师 / 技术爱好者 |
| 特征 | 单人或多小团队;懂命令行;追求效率;对 AI 工具接受度高 |
| 痛点 | 多模型 API key 管理混乱;Agent 工具不可控;产出质量不可验证 |
| 使用场景 | 个人项目开发;用 AI Factory 管理自己的 AI 编码助手;成本优化(多模型切换) |
| 核心诉求 | ① 快速上手(init 引导)② 真实执行可控(审批门)③ 成本透明(usage 统计)④ 免费/低价 |
| 付费意愿 | 低-中(工具订阅 $5-20/月) |
| 技术门槛 | 会用 CLI/懂基本 LLM 概念 |
| 触达渠道 | GitHub / 开发者社区 / 技术博客 / 开源 |

**定位:种子用户(开源获客的第一批)**

## 2. 创业团队画像

| 维度 | 描述 |
|---|---|
| 代表 | 2-10 人初创;CTO/技术合伙人主导 |
| 特征 | 快速迭代;人力有限;希望 AI 承担重复开发工作;成本敏感但愿意为效率付费 |
| 痛点 | 开发速度不够快;AI 工具分散(编码/文档/测试各用各的);无法保证 AI 产出质量 |
| 使用场景 | 一句话创建产品原型;自动开发 feature;AI 员工管理(产品经理/开发/测试角色) |
| 核心诉求 | ① 从想法到产品的完整链路 ② 多 Agent 协作 ③ 产出可验证(质量门)④ 团队可见性(Dashboard) |
| 付费意愿 | 中(团队版 $50-300/月) |
| 技术门槛 | 中(CEO/CTO 均可操作) |
| 触达渠道 | 孵化器 / 创业社区 / 产品 Hunt / AI 创业媒体 |

**定位:早期付费客户(产品验证的核心群体)**

## 3. 企业 IT 画像

| 维度 | 描述 |
|---|---|
| 代表 | 中大型企业 IT 部门 / 平台工程团队 |
| 特征 | 有合规要求;重视治理/审计/权限;预算充足但决策链长;需要私有化 |
| 痛点 | AI 工具不可控(数据外泄/无审计);多个 AI 工具难以统一治理;成本失控 |
| 使用场景 | AI 开发平台统一管理;AI 员工权限治理;审计合规(谁让 AI 做了什么);多模型成本优化 |
| 核心诉求 | ① 治理/审计(Governance OS)② 私有化部署(Docker/离线)③ 权限/审批 ④ 合规报告 ⑤ 与现有系统集成 |
| 付费意愿 | 高(企业版 $10K-100K/年) |
| 技术门槛 | 中高(平台工程团队维护) |
| 触达渠道 | 销售团队 / 企业 IT 展会 / 咨询伙伴 / 客户成功 |

**定位:高价值客户(商业化主力,需 Governance + Enterprise 部署)**

## 4. AI 团队画像

| 维度 | 描述 |
|---|---|
| 代表 | AI 产品团队 / ML 工程团队 / LLM 应用开发者 |
| 特征 | 深度技术;多模型/多 Provider 使用;关注成本/延迟/质量权衡;会自己调优 |
| 痛点 | 模型选型缺乏数据支撑;调用成本不可控;多 Agent 编排复杂;评估体系缺失 |
| 使用场景 | 多模型路由优化;Agent 工作流治理;评估不同模型产出质量;RAG 知识库管理 |
| 核心诉求 | ① Router(智能选型)② usage/成本分析 ③ Evaluation(质量对比)④ 可编程 API |
| 付费意愿 | 中高(开发者版 $30-100/月 或 API 按量) |
| 技术门槛 | 高(专业用户,需要 API/可扩展性) |
| 触达渠道 | AI 会议 / ML 社区 / HuggingFace 生态 / 技术深度文章 |

**定位:意见领袖(影响采购决策,试用 Router/Evaluation 模块)**

## 5. 用户画像优先级矩阵

| 画像 | 规模 | 付费意愿 | 获客成本 | 战略价值 | 优先级 |
|---|---|---|---|---|---|
| 开发者 | 大 | 低-中 | 低(开源) | 种子/口碑 | **1(获客)** |
| 创业团队 | 中 | 中 | 中 | 早期付费 | **2(验证)** |
| AI 团队 | 中 | 中高 | 中(内容) | 意见领袖 | **3(影响)** |
| 企业 IT | 小 | 高 | 高(销售) | 商业主力 | 4(变现,后置) |

## 6. 画像驱动的产品决策

| 决策 | 依据 |
|---|---|
| CLI-first(不先做 UI) | 开发者/AI 团队是种子用户,CLI 是他们的自然入口 |
| 洋葱式开源 | 开发者画像获客成本最低,开源积累口碑 |
| Governance 企业版 | 企业 IT 是最高付费意愿,治理是他们的核心诉求 |
| Router 独立产品 | AI 团队/创业团队都需要多模型优化,独立可售 |
| 创业团队场景(一句话建产品) | 差异化场景,验证"从想法到产品"的完整链路 |
