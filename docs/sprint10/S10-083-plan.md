# S10-083 Production Workflow Closure — Sprint 规划

> 日期: 2026-08-19 | 待用户确认后开发 | 版本目标 v1.1.2

---

## 1. 当前架构分析

```
用户想法 → Discovery(多轮字段收集) → Product Intent → create_product
→ prepare_project (PRD + engineering.json + tasks.json + execution_plan.json)
→ "继续开发" → execute_project → ExecutionOrchestrator
→ per-task: Sandbox(副本) → LLM patch → 副本验证 → artifact 保存 → ✗ 丢弃
```

**断点**: 沙箱副本执行后 patch 不落回项目;验证基于空目录;无 plan 透明;无审批门。

## 2. 已存在能力

| 能力 | 位置 |
|---|---|
| approval.apply(target_dir) git apply | factory-exec/exec/approval.py |
| Sandbox (副本 + apply_patch + 追踪) | factory-exec/exec/sandbox.py |
| ExecutionResult.patch artifact | exec 层 |
| _execute_with_retry (任务落地点) | orchestrator.py:2202 |
| ConfirmationGate (REPL 确认门) | session/confirm.py |

## 3. 缺失能力

| 缺口 | 说明 |
|---|---|
| Patch Delivery | 任务完成后 patch → 真实项目 (approval.apply 接线) |
| Artifact Boundary | 状态文件 (execution_state.json 等) 禁入用户 patch |
| 真实 Validation | 合并后项目跑真实测试; 0 文件 → FAILED |
| Plan Transparency | 查看/修改 Product Plan + Engineering Plan (CLI+API) |
| Human Approval Gate | AI Plan → User Review → Approve → Execute |
| Project Intelligence View | 阶段/进度/能力/风险视图 (CLI+API) |
| Discovery 深度 | 多轮可选 (保存想法/继续讨论/暂不开发) |

## 4. S10-083 完整 Scope

| P | 项 | 交付 |
|---|---|---|
| P0 | Execution Delivery Closure | patch 应用回项目 + 真实验证 + 0 文件 FAILED |
| P0 | Artifact Boundary | patch 白名单 (禁状态文件) |
| P1 | Plan Transparency | factory plan view/edit (CLI) + API 端点 |
| P1 | Approval Gate | execute_project 前 plan 审批 (复用 ConfirmationGate) |
| P2 | Project Intelligence View | 阶段/进度/风险摘要 (CLI + API) |
| P2 | Discovery 保存想法 | 想法库 (可选, 视时间) |

## 5. 技术方案

### P0a: Patch Delivery (最小, 关键)
```
orchestrator._execute_with_retry 成功后:
  outcome 含 patch artifact → 校验白名单 → approval.apply(target=项目目录)
  或直接 git apply (auto-apply, 记录审计)
→ 合并后 → PytestValidator 真实验证
→ 0 代码文件 → 任务 FAILED (非 PASS)
```

### P0b: Artifact Boundary
```
patch 生成端过滤: Agent 不可修改 execution_state.json/task_state.json/
agent_memory.json/workflow 状态文件 (读取允许, 写入从 patch 剥离 + 告警)
实现: exec 层 patch 过滤器 (白名单扩展名/黑名单文件名)
```

### P1: Plan Transparency
```
factory plan show [--project X]    → Product Plan + Engineering Plan 摘要
factory plan edit --field X --value Y → 修改 (写回 engineering.json)
API: GET/PATCH /api/projects/{id}/plan
复用既有 asset 读写 (engineering.json/tasks.json)
```

### P1: Approval Gate
```
execute_project (继续开发) 确认门升级: 显示 plan 摘要 + "确认执行?" 
(已有 ConfirmationGate, 扩展确认消息含 plan 概要)
```

### P2: Project Intelligence
```
factory project view [--project X] → 阶段/完成比例/能力/下一步/风险
API: GET /api/projects/{id}/view
数据源: execution_state.json + project.json lifecycle + artifacts
```
