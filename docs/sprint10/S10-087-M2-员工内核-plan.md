## 1. 任务分解（每个：新建 / 复用 / 验收）

### A1 `session/agent_entity.py` — 专家实体模型（新建）
- `AgentEntity{id, role, industry, provider{id,model}, system_prompt, skills[], knowledge_ref, workflow_ref, memory_ref, tools[], evaluation_ref, profile{success_rate,quality,cost,speed,samples}}`
- **复用**: core/agents.Agent 字段口径 · exec.DeveloperAgent 配置
- **验收**: 序列化/落盘/加载 roundtrip；字段齐；职责边界注释（entity=身份, DeveloperAgent=执行）

### A2 `session/agent_registry.py` — 工厂层注册表（新建，薄包装）
- `AgentRegistry.add/get/list(industry)` · 行业命名空间（it.* / ops.*）· 持久化 agents.json
- **复用**: `session/agents.py` 的 AgentRegistry.load/list · core/agents/registry
- **验收**: 注册/取用/列表；同 role 多 provider 并存；行业隔离

### A3 `session/expert_factory.py` — 专家装配器（核心，"造专家"落地）
- `ExpertFactory.assemble(role, skills[], knowledge_ref, workflow_ref, provider) → AgentEntity`；校验 skill 存在、workflow 可执行、knowledge 可挂载
- **复用**: skills 注册表 · workflow_engine · provider 路由
- **验收**: 装配出 7 个软件行业专家；缺 skill → 明确报错（不静默）；无 LLM → 确定性兜底可用

### A4 `session/handoff_bus.py` — 交接总线（多 Agent 协作）
- `HandoffBus.route(role_graph)` · `send(producer→consumer)` · 消息结构 `{from, to, artifacts[], decisions[], constraints[]}`；资产 parent_artifact 互引；冲突 → ReviewGate
- **复用**: artifact_registry · ReviewGate · ConflictResolver（S10-057 已有）
- **验收**: PM→Market→…→SeniorPM 依次消费上一产出；每资产含 parent_artifact；冲突挂起等审批

### A5 接线 `actions.product_pipeline`（改造）
- 用 ExpertFactory.assemble + HandoffBus 替换 7-prompt 循环；`created_by=agent_id`（非 role 字符串）
- **复用**: ProductIntelligenceEngine / pipeline.py 作为各角色确定性兜底
- **验收**: `让PM分析` 走真 Agent 链；证据/资产链不回归

### A6 多 LLM 路由（后置，本次不做）
- planner/executor/reviewer 分档路由 —— 记入 backlog，不进 M2 主验收
