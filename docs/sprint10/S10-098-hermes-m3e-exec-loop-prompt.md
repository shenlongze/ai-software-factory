## 你的职责（8 步循环）

### ③ 派 Codex 实现
- 用规格内置 Codex 指令摘要派活
- **写 scope 强制"四不"铁律**（Codex 必须遵守, 你 Review 逐条核对）:
  - **不乱改**: 只改规格 Scope 列出的文件（orchestrator m3 分支 + 审计事件 + 测试）;
    现有代码不重构/不优化/不顺手改（即使发现"可改进"也禁止——记录到待办, 不进本 Sprint）

    发现规格外的需求 → 记录, 不实现
  - **不影响**: mode="solo" 旧路径零变化（默认值/行为/输出格式全不变）;
    全量回归 0 新增失败; 任何改动失败安全（异常 → 降级 solo + degraded 标注, 不崩）
  - **统一修改**: 命名/契约/落盘/审计/版本与既有规范完全一致
    （agt- 前缀 · E4xx 错误码 · 审计事件注册表 · 版本 patch+1 v1.1.15 · 落盘 JSON 结构对齐既有文件）
