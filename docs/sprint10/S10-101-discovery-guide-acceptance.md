## 2. 关键设计验证（反虚标）

- **进度确定性**: format_progress/lifecycle_line 纯状态计算, env -u (无 LLM) 两路径均显示 — 非 LLM 产物
- **求助诚实降级**: LLM help_request → 建议; 无 LLM → HELP_KEYWORDS 硬闸 + DEFAULT_SUGGESTIONS
  (确定性默认, 非伪造 LLM); 求助输入绝不当字段内容
- **中间字段 LLM 化**: field_answer apply 后下一问优先 analysis.smart_questions[0] (带理由),
  空/失败 → 机械模板 (诚实)
- **两路径同步**: 共享 discovery_guide.py 唯一来源; 修复 5084497 使 DS 首问 (driver 渲染路径)
  与 conversation 一致

## 3. 验收中发现并修复的缺陷（工程资产）

- **DS 首问缺进度前缀**: start() 的 questions[0].question 与 actions.discovery_start 渲染
  ("我先帮你梳理需求。\n"+q) 无进度/生命周期, 而 conversation 首问有 → 两路径不同步。
  修复 (5084497): `_guide_message` 幂等 + `_next_question()` 统一装饰 + `_last_system_question`
  存原始问题 (LLM 上下文干净)。6 新测试 + 5 处旧断言按新格式更新 (逐条注释)。
