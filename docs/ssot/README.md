# AI Factory OS — 单一事实源（SSoT）

本目录是本仓库**唯一的事实源**。其余一切文档（方案书 / 说明书 / 调研 / 规划 / 清单）一律降级为"输入"或"派生视图"。

## 三层 SSoT

| 层 | 文件 | 谁写 | 谁读 | 更新频率 | 冻结 |
|----|------|------|------|---------|------|
| **Product** | `product.md` | 人（Founder） | 所有人 | 极少 | 冻结（改动需显式裁决） |
| **Architecture** | `architecture.md` | 人（Founder/架构师） | 工程 | 少 | 冻结（改动需显式裁决） |
| **Reality** | `reality/` | **机器自动生成** | 所有人 | 每次代码变更 | **禁止手写** |

## 冲突时的引用顺序

```
Reality  >  Architecture  >  Product  >  其他一切文档
```

- 代码真实状态（Reality）优先于架构意图（Architecture）优先于产品定义（Product）。
- 任何与上层冲突的文档，一律以本目录为准。

## 旧文档处置声明

本仓库所有 v3.x 方案书 / 产品说明书 / 开源调研 / 竞品对比 / 差距追赶 / 能力缺口 /
员工管理 / 总体计划 / 战役规划 / 会话系统 / 外部执行器网关 等文档：

> **一律降级为"输入"或"派生视图"，不得再作为"当前事实"引用。**

## 新增文档的两条归宿

1. **派生** — 由某一层 SSoT 派生（须标注来源 + 生成方式）
2. **归档** — 进 `archive/`（不再具有事实效力）

> 除此之外，不允许新增任何"事实类"文档。
