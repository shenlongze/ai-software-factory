# AI Factory OS — 产品定义（SSoT v0.1 骨架）

> 状态: 骨架（索引，非内容） | 冻结: 是（改动需显式裁决）

## 1. 一句话

让一个人通过自然语言，组织 AI 完成任何复杂工作。

## 2. 是什么 / 不是什么

**是**：企业级 AI Operating System（企业软件基座）。
**不是**：Coding Agent / IDE / 框架 / 软件工厂 / 单纯的 Agent 工具。
OS 提供平台、调用、调度、治理、记忆、扩展；具体能力由插件提供。

## 3. 三层身份

- **OS 本体** — 平台：会话入口、编排、治理、记忆学习、扩展生态
- **Software Factory** — 第一个 Factory（**CURRENT**，非边界）
- **其他 Factory** — 后续扩展（**EXPANSION**），如 Data / Ops / Marketing / 行业

## 4. 用户主链（唯一）

```
Idea → 目标表达 → 理解 → 编排 → 执行 → 验证 → 交付 → 经验回流
```
用户只表达目标；系统内部完成结构化。全程可审计、可回溯。

## 5. 五个平台能力

1. **会话** — 唯一业务入口
2. **编排** — 能力解析与调度（无固定流程）
3. **治理** — 审批 / 预算 / 审计 / 证据
4. **记忆学习** — 记忆、经验、自我修复与提升、越用越懂用户
5. **扩展生态** — Agent / Skill / Tool / MCP / Model / Provider 的统一管理

## 6. 边界

- 用户只表达"我想完成什么"
- 系统内部负责结构化（不要求用户理解底层实现）
- 不绑定任何具体模型 / 工具 / 厂商
- 核心基座 + 一切插件

## 7. 终态（不承诺时间）

一个能够**创建、管理、运行和进化 AI 公司**的操作系统。
让每个人都能经营一家 AI 公司。
