## 5. 执行规则

1. 每个子项: 独立 commit + 测试 + 文档，验收通过才进下一个（沿用 K 系列铁律）
2. 完成 → 更新 FEATURES/CAPABILITY_MATRIX/CHANGELOG + 本文件状态表 + backlog 状态
3. 每 Sprint 结束跑一次全量评测（K-5），用数据背书
4. 防遗漏: 注册表/对称路径改动受 P0-10/P0-11 门禁保护
