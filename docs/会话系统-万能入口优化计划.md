## 1. 愿景升级: 会话 = 万能入口 + 全息过程

```
用户 → 会话 (自然语言)
         │
         ├─ 思考过程 → 流式可视化 (thinking 事件, 前端展示推理链)
         ├─ 执行过程 → 工具调用实时展示 (tool 事件: 参数/结果/耗时/ok)
         ├─ 计划过程 → 计划卡片可编辑 (Plan 阶段)
         ├─ 决策过程 → 批准门 (APR 审批卡, 留痕)
         ├─ 审计链 → 所有动作落 audit (谁/何时/做了什么/结果)
         ├─ 落库 → 统一事件库 (SQLite: 会话/消息/事件/审计/记忆 一体)
         └─ 回溯 → 时间旅行 (任意时间点快照/重放/恢复)
```

### 设计哲学 (抄主流)

| 原则 | 来源 | 落地 |
|------|------|------|
| 窄腰核心, 能力在边缘 | Hermes | 核心工具 ≤10, 其余 tool_search |
| 缓存神圣 | Hermes | 系统提示字节稳定 |
| 渐进式披露 | Pi Agent | 首轮少量工具按需展开 |
| 验证循环 | Codex/Claude | 不全信模型, 代码兜底 |
| 会话级生命周期 | passbaton/Claude | SessionStart/PreCompact/SessionEnd |
| 事件真源, 记忆派生 | centri/OpenClaw | 审计链为真, 记忆从事件提取 |
| 任务控制面 | OpenClaw SQLite | 审计/归属/状态/成本 统一查询 |
| Tracing 范式 | Langfuse/LangSmith | 每次会话一条 trace: 节点+耗时+token+成本 |
| 时间旅行 | Trae/Claude --resume | 会话快照 + 重放 + 恢复 |

## 3. 丝滑/有效/可审计 三性验收

### 丝滑 (交互)
- 流式响应首 token < 2s; 工具事件实时可见
- 100 轮长会话不卡 (T1 分层)
- 消息可编辑/重发/回滚 (T16/T13)
- 计划卡片可视化可编辑 (T4)

### 有效 (结果)
- 工具真实执行 + 结果回喂 (已有 A 兜底)
- 证据链: 每句回答可溯源 (T5)
- 全量回归: 每次改动 485+ 测试通过

### 可审计/可治理/可回溯 (本轮核心)
- 每次会话一条 trace: 节点/耗时/token/成本 (T12)
- 所有动作留痕: 谁/何时/什么/结果 (T6)
- 红线规则可配置, 违规自动拦截或转批准 (T7)
- 任意时间点恢复: 会话快照 + 重放 + 分支 (T13)
- 审计/追溯查询: CLI + API + WebUI (T8/T14)

## 5. 执行顺序与依赖

```
Phase 1 (T1+T2) ─→ Phase 2 (T3+T4+T5) ─→ Phase 3 (T6+T7+T8)
      │                    │                    │
      ↓                    ↓                    ↓
Phase 4 (T9+T10+T11) ←── Phase 5 (T12+T13+T14) ←─┘
      │                    │
      ↓                    ↓
Phase 6 (T15+T16+T17) ←───┘ (T12 统一库是所有查询的地基)
```

依赖要点:
- T3/T4 依赖 T1 (长会话过程可视才有意义)
- T6/T8 依赖 T12 (审计查询要先统一库)
- T13 依赖 T12 (快照落统一库)
- T7 独立可并行

每阶段独立 commit, 每任务走 B 闭环验证。

预估总工期: ~31 天 (5+5+5+5+6+5), 并行 T1/T6、T3/T7、T9/T15 可压到 ~20 天。

## 6. 风险与对策

| 风险 | 对策 |
|------|------|
| 分层上下文丢关键信息 | L0 摘要保留实体/决策; 每层 trace 可观测 |
| 审计全量落库性能 | 批量写 + 异步队列; 只审计动作不审计内容全文 |
| 统一库迁移丢数据 | 双写过渡 (JSON+SQLite 并行 1 周); 校验脚本对比 |
| 时间旅行复杂度爆炸 | 先做"恢复到点"不做"分支"; 分支 v2 |
| 治理规则误拦截 | 规则默认只记录不拦截; 灰度开启 |
| 过程可视化拖慢前端 | 事件节流 + 虚拟滚动; 折叠默认收起 |
