# 会话驱动：操作引擎 + 全能入口（发起 / 查看 / 跳转）

> 日期: 2026-08-26 · 状态: Founder 确认方向 · 依据: "全部功能都可以由会话发起、
> 查看进度、直接跳转到对应功能，看任务/进度等，全部都可以"

## 1. 定位

**会话是命令中心，UI 是展示**。任何功能都可以：
1. **发起**（initiate）— 会话触发真实动作（创建项目/生成PRD/启动开发/改需求…）
2. **查看**（view）— 会话查真实进度/任务/质量/文档（query_engine 已有）
3. **跳转**（jump）— 回答带深链 target，点击直达对应功能页

## 2. 链路

```
用户输入
  → LLM 转标准意图 {intent, project}（query_engine，已有）
  → 执行器：
      query intent → 本地查真实数据（已有）
      action intent → 复用现有引擎执行（新增 P1/P2）
  → 标准输出 + meta {intent, project, data_source, target:{url,label}}
  → 前端渲染：回答 + 「→ 跳转按钮」
```

## 3. 意图集合（统一 schema）

| intent | 类型 | 动作/查询 | 跳转 target |
|---|---|---|---|
| list_projects | query | 项目列表(阶段/⭐) | #/workspace/projects |
| project_status | query | 生命周期/进度/当前阶段 | #/project/{id} |
| project_quality | query | 质量分 | #/project/{id}/quality |
| project_tasks | query | 任务统计 | #/project/{id}/todo |
| project_docs | query | 文档清单 | #/project/{id}/docs |
| model | query | 当前模型 | #/workspace/settings |
| create_project | **action** | 创建项目(复用 create_project) | #/project/{id} |
| generate_prd | **action** | 生成 PRD(复用管线) | #/project/{id}/docs |
| start_dev | **action** | 工程计划+任务+启动 workflow | #/project/{id}/workflow |
| change_request | **action** | ChangeControl 变更回流 | #/project/{id}/todo |
| chat | — | 普通对话 | — |

## 4. 动作执行器（P1/P2，复用现有引擎不重造）

- **P1 规划**: create_project / generate_prd
- **P2 开发**: start_dev / change_request / 任务状态操作
- **P3 治理**: 高危动作(删除/审批/启动执行)先给方案→用户确认→执行→审计

## 5. 跳转（第一版先做）

- query_engine.intent_target(intent, project_id, project_name) → {url, label}
- adapter meta.target 注入
- 前端 assistant 消息下方渲染「→ {label}」按钮（hash 跳转）

## 6. 验收

- 查看: 问"有什么任务" → 真实任务统计 + 「查看任务 →」按钮直达任务页
- 发起(P1): 说"做一个记账App" → 真实创建项目 + 跳转项目页
- 全程真实数据 + 标准输出 + 审计
