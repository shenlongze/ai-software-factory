## 1. P0 — 立刻做（本周）

### 1.1 测试可复现（104 失败清零）

**目标**: 全量 pytest 13006 用例 0 失败、可重复复现。

| 子项 | 现状 | 动作 | 验收 |
|---|---|---|---|
| factory_runtime 系失败 | 沙箱权限 (Operation not permitted) | 定位权限边界（进程 spawn/端口绑定），改为可控临时目录/环境变量注入；CI 环境适配 | 单跑/全量均 0 失败 |
| llm 系偶发失败 | 全量跑顺序依赖、单跑恒过 | 排查共享状态（全局配置/单例/monkeypatch 泄漏），加隔离 fixture | 全量连跑 2 次 0 失败 |
| 全量时长 | ~3.6 分钟 | 分层: fast(单元) / slow(集成) 标记，P0-5 发布门只跑 fast | 发布门 <1 分钟 |

### 1.2 API 认证最小化

**目标**: 消除最高危面（`POST /api/system/update` 可触发 git pull + pip install）。

| 子项 | 动作 | 验收 |
|---|---|---|
| 本地 token | 启动时生成随机 token 写入 `~/.factory/api_token`，`factory start` 打印；前端首次访问输入/自动读入 | 无 token 请求高危端点 → 401 |
| 高危端点保护 | `/api/system/update`、`/api/external-ai/run`、删除类端点强制 token | 有 token 可用、无 token 拒绝 |
| 审计 | 认证失败/成功落审计事件 | 事件可查 |

### 1.3 数据备份/恢复

**目标**: `~/.factory/` 数据可备份、可恢复。

| 子项 | 动作 | 验收 |
|---|---|---|
| 备份命令 | `factory backup`（SQLite WAL checkpoint + JSON 目录打包，原子） | 备份产物可校验 |
| 恢复命令 | `factory backup restore <file>`（先校验再落盘） | 恢复后事件库/项目状态一致 |
| 定时 | 可选 cron/launchd 示例脚本 | 文档化 |

## 2. P1 — 主线继续

### 2.1 K-7 Web 全链路产品化

**目标**: 创建项目→发现→PRD→工程→审批→执行 全流程 Web 可用，与 board 同数据源。

| 子项 | 动作 | 验收 |
|---|---|---|
| 发现对话 Web 化 | React 接入 `/api/projects/{id}/discovery/*`（已有端点） | Web 可完成发现→确认→PRD |
| 执行触发 | 前端触发 `/api/projects/{id}/start` + run-status 轮询/SSE | Web 可发起执行并看进度 |
| 审批可视化 | 审批列表 + approve/reject 按钮（已有端点） | Web 完成审批闭环 |
| 与 board 统一 | 共用同一状态源，无 mock | P0-11 对称路径测试绿 |

### 2.2 RAG 增强

| 步骤 | 动作 | 验收 |
|---|---|---|
| 第一步（零依赖） | jieba 分词 + 同义词表 + BM25 打分替换纯 TF | 中文召回/排序提升可断言（对比用例） |
| 第二步（可选） | ollama embedding (nomic-embed-text) + 内存余弦索引 | 语义相关查询命中 |
| 第三步 | LLM 答案生成（检索→总结带引用） | 真"问答"形态，引用可溯源 |

### 2.3 巨型文件拆分

| 文件 | 现状 | 动作 | 验收 |
|---|---|---|---|
| service.py | 4812 行 | 按域拆 service_*.py（project/approval/experience...） | 135 端点契约零回归 |
| fastapi_adapter.py | 4255 行 | 按路由域拆 routers/ 子包 | 全量测试绿 |

## 5. 执行规则（沿用 K 系列）

1. **一次一个战役/子项**，独立验收，通过才进下一个
2. **可断言验收**：不接受"做了但没法证明"
3. **防遗漏**：注册表/对称路径改动受 P0-10/P0-11 门禁保护
4. **诚实**：完成→更新 FEATURES/CAPABILITY_MATRIX/CHANGELOG 三处 + 本文件状态表
5. **每子项独立 commit + 测试 + 文档**
